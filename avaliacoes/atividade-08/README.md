# Atividade 8

### Orientações Gerais

- Seguir as orientações presentes no arquivo anexo.
- O projeto será desenvolvido em equipe, com **no máximo 4 alunos**.
- O trabalho exigirá uma pesquisa sobre **virtualização no Linux**.
- Na aula de quinta-feira, o professor estará disponível para esclarecer dúvidas.

### Entregas do Projeto

1. **Arquivo `.doc`** — Documento contendo as respostas às questões solicitadas na atividade.
2. **Arquivo `.pptx`** — Apresentação de slides sobre o trabalho/projeto.
3. **Apresentação oral** — Apresentação do projeto pela equipe.

### Avaliação da Apresentação

Durante a apresentação, os integrantes das equipes serão questionados individualmente, com o objetivo de verificar a participação e a contribuição de cada aluno no desenvolvimento do projeto.

### Datas e Prazos

1. **Prazos das entregas:** serão definidos posteriormente pelo professor.
2. **Formação das equipes:** os alunos devem definir os integrantes e enviar os nomes pelo mural da disciplina ainda hoje.
3. **Limite de integrantes:** cada equipe poderá ter, no máximo, **4 componentes**.
